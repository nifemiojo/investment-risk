# Open Questions

**Status**: Living backlog — add freely
**Date**: 2026-08-14

---

## Purpose

A low-friction inbox for questions and curiosities that surface while designing and operating the risk system. Capture first, decide relevance later. No question is too small, too obvious, or too far outside the current scope to write down.

This is deliberately separate from `design/insights/` (learnings already synthesised) and `design/artifacts/` (what the system produces). A question is unresolved — it hasn't yet become an insight, a design decision, or a feature.

---

## How To Use This Folder

1. **Dump first.** When a question pops up (in a design doc, a notebook, a conversation), create a new file at `open-questions/NNN-slug.md` and add it to the list below. Don't wait until you've researched it.
2. **Tag a status.** Most start as `open`. Move to another state when appropriate.
3. **One file per question.** Each question gets its own short markdown file. The question itself is the title.

### Statuses

| Status | Meaning |
|---|---|
| `open` | Captured, not yet explored. |
| `exploring` | Actively being worked through. |
| `answered` | Resolved — record the answer and where it lives. |
| `promoted` | Grew into an insight, a design doc, or an artifact. |
